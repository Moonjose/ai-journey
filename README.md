# ai-journey

Study repository: learning AI from scratch, coming from a game development background.

The end goal is to bring the two together, reinforcement learning and LLMs running as real-time inference inside a game.

## Layout

```
.
├── part-1-foundations/
│   └── ch-01-python/
├── part-2-deep-learning/
├── part-3-reinforcement-learning/
├── part-4-language-models/
├── part-5-realtime-inference/
└── part-6-portfolio/
```

Each chapter holds its notebooks and, where there is one, the matching project.
